# 台股研究室｜市場資料分析示範

將原本分散在 Jupyter Notebook 的教學主題整合成一個可互動的靜態網頁：市場總覽、個股查詢、歷史分析、新聞情緒與模型實驗室。

## 開啟方式

在此資料夾啟動任何靜態網站伺服器，然後瀏覽 `index.html`。目前部署版本只包含前端程式，因此使用程式內建的六檔股票清單；若要加入完整代碼表，可另行提供 `stockidname.csv` 並部署。

## GitHub Pages

1. 將網站檔案推送至 GitHub 倉庫。
2. 在倉庫的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選擇包含 `index.html` 的分支與根目錄，儲存後即可取得網站網址。

這個版本只包含靜態前端，沒有 API 金鑰或伺服器端服務。若要接回即時行情、新聞爬取或 Gemini 分析，需要另建後端，將金鑰放在後端環境變數中，並由前端呼叫後端 API。

## 示範資料說明

- 行情圖表、快照、漲跌排行和歷史統計均為合成示意資料。
- 新聞標題和情緒判斷均為虛構的介面範例，沒有連線至 Yahoo 新聞或 Gemini。
- 模型頁面展示預測流程概念，不會執行模型，也不提供真實股價預測。
- 歷史分析頁可以下載帶有示範標記的合成 CSV。

請勿將本示範的數值或輸出作為投資、交易或研究結論。
